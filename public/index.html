    终端用法

    不需要密钥。curl、wget、HTTPie 访问根路径得到一行 IP；浏览器访问同一地址得到这个页面。/json 和 /api/whoami 的字段相同。

    # 一行 IP。-L 用来跟上跳到 HTTPS 的重定向
curl -L https://你的域名

# 完整字段。pretty 只影响换行
curl -sL https://你的域名/json?pretty

wget -qO- https://你的域名

    Windows PowerShell 里的 curl 往往是 Invoke-WebRequest 的别名。请改用 curl.exe -L https://<域名>。

    数据与限制

    • 边缘接口读的是 Cloudflare 看到的连接：客户端 IP、request.cf 里的国家、城市、经纬度、ASN、机房和 TLS。没有单独的 ISP 字段，所以这时 isp 为空，org 来自 asOrganization。
    • 查任意 IP 时依次请求 ipwho.is、api.ip.sb、geojs.io、ipapi.co。城市是近似值，机房和移动出口更容易偏。
    • 域名解析不经过本站。某家解析少给几条 TXT 时，页面会改用更完整的那一份。
    • 没有数据库，没有 API key，页面里也没有第三方统计脚本。
    为什么城市和我实际所在地不一样？

    查到的是出口地址的登记位置。城域网集中出口、代理、VPN、云主机和运营商级 NAT 都会让城市偏离你本人。任何 IP 查询都看不到设备的物理位置。

    这个站会记下我查过什么吗？

    服务端不落库。最近查询存在你自己的浏览器里，可以在上面一键清除。

    风险分是怎么来的？

    本地关键词：云厂商、托管、代理或 VPN 会加分，住宅和移动网络保持低分。名称缺失时，只用一小份常见 ASN 对照。四档分别是 0–19、20–39、40–69、70–100。
